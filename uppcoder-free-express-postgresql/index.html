Uppcoder 免费部署 Express 应用，配 PostgreSQL 数据库

Uppcoder 免费部署 Express 应用，配 PostgreSQL 数据库
Breeze882026-11-202026-11-24

想把 Express 应用免费部署上线、还带一个真正的 PostgreSQL 数据库？Uppcoder 的免费 Spark 档可以做到：不用绑卡，也没有使用期限，适合做小项目、练手和演示。

免费档给什么？

  • 一个应用加一个数据库：内存 2GB、磁盘 2GB，数据库是 PostgreSQL 17；
  • 浏览器里直接写代码的编辑器和终端，和应用跑在同一个容器里，改完保存就自动重启；
  • 上线第一分钟就有自己的 HTTPS 地址；
  • 支持从自己的编辑器用 SSH 连上去（VS Code Remote - SSH、Cursor、JetBrains Gateway、Zed 都行）；
  • 每天夜间备份到独立服务器，免费档也包含。

怎么开通？

  1. 到 portal.uppcoder.com 注册账号；
  2. 依次点 Billing、Available Plans、Spark、Start free（先验证邮箱：点 Send me the link，再点邮件里的链接）；
  3. 想一键上手，打开 github.com/Uppcoder/express-postgresql-starter，点 Deploy to Uppcoder，给应用起个名字，确认部署即可。平台会自动克隆仓库、跑 npm install 并启动应用。

数据库怎么连？

应用通过 DATABASE_URL 拿到完整连接串，另外还有 POSTGRES_HOST、POSTGRES_PORT、POSTGRES_DB、POSTGRES_USER、POSTGRES_PASSWORD 等分项环境变量，密码不用写进代码里。示例项目用 pg 包读 DATABASE_URL，运行在 Node 22 上。

几个注意事项：

  • 应用默认是私有的，只有登录后才能访问；想公开访问，在 stack 页面把 Private 切换成 Public，立即生效，不用重启；
  • /health 这个路径被平台自己占用做健康检查，自己的状态接口请换个名字，比如示例里的 /status；
  • 自带项目也可以：新建空白 stack，贴上自己仓库的 https 地址（私有仓库要给 access token），平台会按顺序找 index.js、package.json 的 main、server.js、app.js、src/index.js，找不到就跑 npm start，记得监听 process.env.PORT；
  • 官方承诺免费档没有使用期限，如果以后要改或要结束，会提前至少 60 天发邮件通知。

原文教程见 Medium：Deploy an Express App with PostgreSQL for Free — Uppcoder。
